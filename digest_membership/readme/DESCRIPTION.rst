=================
Digest Membership
=================

This module extends the Digest application by adding membership-related
Key Performance Indicators (KPIs) to digest emails.

Features
========

The following KPIs can be enabled in digest configurations:

* **New Members** – Number of members created.
* **Donations** – Number of completed donation transactions.
* **Donation Amount** – Total amount of completed donation transactions.
* **Activity** – Number of membership activities created.

These KPIs help organizations monitor membership growth, engagement,
and fundraising activity directly from their periodic digest emails.

Usage
=====

#. Go to **Settings → Statistics → Digest Emails**.
#. Open or create a digest.
#. Enable one or more membership KPIs:

   * New Members
   * Donations
   * Donation Amount
   * Activity

#. Send the digest email.

The selected membership statistics will be included in the digest report.
